# Wireframes

Low-fidelity, clickable wireframes for 70 screens (child app on tablet, parent app on phone, teacher and staff on desktop). Each `.dc.html` file is one screen; `canvas.json` lays them out on three pages (child, parent, teacher). Open any `.dc.html` file in a browser to view a single screen.

The interactive prototype in `prototype/` supersedes these for behaviour and device layouts.
